# مراجعة الدفع والإيصالات

تمت معاينة `/create-ad` و`/profile` على Web بعرض 390×844.

شاشة الملف الشخصي تعرض قسم «إعلاناتي الترويجية» ببطاقتين تجريبيتين: حملة قيد المراجعة وحملة فعالة، مع المدة والسعر ورابط إنشاء حملة جديدة.

شاشة إنشاء الإعلان تعرض المسار العام بنجاح، بينما تظهر بيانات الدفع ورفع الإيصال في الخطوة السادسة بعد اختيار «إعلان ترويجي». بيانات الحساب والمستفيد محفوظة في `lib/payment-config.ts` وقابلة للنقل إلى إعداد خادمي محمي قبل الإنتاج.

الفحص النهائي نجح: TypeScript بلا أخطاء و22 اختباراً ناجحاً مع اختبار تسجيل الخروج المتجاوز.
