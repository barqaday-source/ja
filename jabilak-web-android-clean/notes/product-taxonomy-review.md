# مراجعة تصنيف المنتجات

تمت معاينة `/products` و`/explore` على Web بعرض 1366×768.

تظهر شاشة المنتجات الآن بستة منتجات، منها منتج أحذية رياضية، ويعرض كل صف التصنيف العام والنوع المكتشف مثل «ملابس» أو «أحذية» أو «إكسسوارات». قائمة الفلترة تتضمن أنواع المنتجات إلى جانب حالات المخزون والنشر.

تظهر شاشة البحث فئات مستقلة تشمل الملابس والأحذية، وتعرض نتائج الأحذية عبر متجر «ستيب ستايل» مع وسم «النوع: أحذية». الفلترة تعتمد على النوع المكتشف أو اسم الفئة، مع بقاء الفلاتر الأخرى فعالة.
