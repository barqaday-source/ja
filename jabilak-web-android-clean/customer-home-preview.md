# Customer home preview

تم تنفيذ الصفحة الرئيسية للزبون فقط وفق المرجع: هيدر RTL خفيف، عنوان رئيسي، زر إشعارات دائري، شريط بحث، فلاتر أفقية، عنوان قسم مع عرض الكل، بطاقة مساحة التاجر، وبطاقات متاجر ثنائية الأعمدة مع شارة، حفظ، موقع، ووصف مختصر.

تم استخدام ألوان تاجر الديناميكية من useColors مع الحفاظ على الباليت الحالية، وتنقل سفلي عائم بالأيقونات. التفاعلات الموجودة: البحث النصي، تغيير الفئة، حفظ المتجر، فتح المتجر، فتح الاستكشاف، وفتح مساحة التاجر.

تم التحقق من TypeScript والبناء ومن عرض الصفحة على 390x844. بقية المسارات لم تُعدّل ضمن هذه المرحلة.
