# الشاشة 04 — لوحة تحكم الشركة

تم تنفيذ لوحة الشركة فقط وفق المرجع: هيدر داكن باسم الشركة وحالة التوثيق، بطاقة مبيعات رئيسية قابلة لتبديل الفترة، الاشتراك، أربع بطاقات إحصاءات، شبكة إجراءات سريعة، وقائمة آخر الطلبات.

الإجراءات مرتبطة بتدفقات فعلية داخل النسخة التجريبية: إضافة منتج تفتح النشر، المنتجات والمخزون يفتحان المخزن، بينما الإعلانات والتقارير والطلبات تعرض حالات واضحة قابلة للتوسعة لاحقاً. الطلبات قابلة للنقر وتعرض تفاصيلها التجريبية.

تم الحفاظ على RTL والهوية والبطاقات والشريط السفلي، ولم يتم تعديل الشاشات 01 و02 و03 أو بناء الشاشة 05. المعاينة على 390x844 وTypeScript والبناء ناجحان.
