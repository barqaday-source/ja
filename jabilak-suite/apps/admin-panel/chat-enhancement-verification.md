# تحقق إضافة أداء الدردشة والمرفقات

نجح فحص TypeScript وLint. نجحت اختبارات Vitest: 12 ملفات، 38 اختباراً ناجحاً، واختبار واحد متخطى. أضيف اختبار `tests/chat-performance.test.ts` للتحقق من إنشاء 240 رسالة، فريدة المعرفات، وتنوع النص والصور والملفات.

أضيفت `createPerformanceMessages` في `lib/chat/mock.ts`، وربطت محادثة شركة الأناقة ببيانات اختبار كبيرة. أصبحت شاشة `app/chat/[id].tsx` تستخدم FlatList مع virtualization، وتعرض الصور والملفات داخل فقاعات تفاعلية. أضيف `expo-document-picker` واختيار الملفات العامة مع الاسم والنوع والحجم، وحالات التحميل والإلغاء والفشل، كما يدعم اختيار الصور وعرضها.

تعذر الفحص البصري لأن خادم المعاينة المدارة لا يرى العملية اليدوية ثم أصبح الرابط العام غير متاح؛ يلزم إعادة تشغيل خدمة المعاينة قبل التحقق البصري النهائي.
