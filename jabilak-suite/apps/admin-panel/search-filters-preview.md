# الشاشة 06 — فلترة البحث المتقدمة

تم تنفيذ شاشة الفلترة فقط بواجهة RTL مستوحاة من المرجع، وتشمل الفئة، المحافظة، المنطقة، نطاق السعر، التقييم، الشركات الموثقة، توفر المنتج، نوع المتجر، وترتيب النتائج. المحافظات والمناطق والخيارات تظهر بقوائم قابلة للفتح، بينما السعر Range Slider بمقبضين قابلين للسحب لتحديد الحد الأدنى والأعلى.

زر إعادة التعيين يعيد القيم الافتراضية، وزر تطبيق الفلاتر يعرض ملخص الاختيارات ثم يعيد المستخدم إلى نتائج البحث. تم الحفاظ على الشاشات السابقة وعدم بناء الشاشة 07. TypeScript والبناء والمعاينة على 390x844 ناجحة.
