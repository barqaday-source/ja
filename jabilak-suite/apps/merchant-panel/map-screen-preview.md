# الشاشة 07 — الخريطة والمواقع

تم تنفيذ شاشة الخريطة فقط. على iOS وAndroid تستخدم الشاشة react-native-maps بخريطة حقيقية تفاعلية ومؤشرات Marker وموقع المستخدم، بينما توفر معاينة الويب خريطة تفاعلية بديلة للمؤشرات لأن react-native-maps مكتبة Native-only.

تتضمن الشاشة بحثاً عن شركة أو موقع، تحديد موقعي، فلاتر الأقرب والتصنيف ومفتوح الآن وموثق، مؤشرات قابلة للضغط، وبطاقة سفلية تعرض الشعار والاسم والتوثيق والتقييم والمسافة والتصنيف والحالة مع أزرار الاتصال وفتح الشركة. TypeScript والبناء والاختبارات والمعاينة ناجحة، ولم تُعدّل الشاشات 01–06 ولم تُبنَ الشاشة 08.
