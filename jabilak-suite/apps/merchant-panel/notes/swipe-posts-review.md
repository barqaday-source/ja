# مراجعة تجربة المنشورات

تمت معاينة `/reels` على Web بعرض 390×844 و1366×768.

تظهر بطاقات المنشورات بعرض متجاوب، وتعمل القائمة الخارجية بالسحب العمودي للانتقال بين المنشورات مع توقف مناسب لكل بطاقة. داخل كل منشور أصبح هناك سلايدر أفقي للوسائط، مع بقاء أزرار التعديل والحذف والإعجاب والمشاركة واضحة.

تمت إضافة «حفظ المنتج» مع حالة «تم الحفظ»، و«تنزيل المنتج» مع حالة تحميل قصيرة ثم رسالة نجاح. على Web يفتح التنزيل رابط الصورة التجريبية في المتصفح، وهو جاهز لاحقاً للاستبدال برابط ملف Storage حقيقي.
