# إعدادات الإدارة المركزية

## الغرض

يستخدم التطبيق حالياً `PREVIEW_ADMIN_SETTINGS` كمصدر محلي للمعاينة. عند بناء تطبيق الإدارة، يُستبدل هذا المصدر بمستودع Supabase أو API خادمي مع صلاحيات مسؤول فقط.

## الحقول المقترحة

| المجموعة | الحقل | الاستخدام |
|---|---|---|
| الدفع | `bankName` | اسم المصرف الظاهر للمستخدم |
| الدفع | `beneficiary` | اسم المستفيد الرسمي |
| الدفع | `accountNumber` | رقم الحساب مع زر نسخ |
| الدفع | `iban` | IBAN مع زر نسخ |
| التواصل | `whatsappNumber` | فتح WhatsApp لإرسال تفاصيل الدفع أو مراسلة المتجر |
| التواصل | `supportPhone` | زر الاتصال بالدعم |
| التواصل | `supportWhatsapp` | WhatsApp الدعم |
| التواصل | `supportEmail` | بريد الدعم |
| الحملات | `promotionalPlans` | أسعار ومدد الحملات القابلة للتعديل |

## قرار الأمان

لا ينبغي أن يحتوي التطبيق المنشور على مفاتيح إدارية أو صلاحيات تعديل. يقرأ المستخدم الإعدادات العامة فقط، بينما تُجرى تعديلات الحسابات والأسعار من لوحة الإدارة عبر جلسة مسؤول وسياسات RLS. يجب نقل بيانات الحساب المصرفي من الكود إلى مصدر خادمي محمي قبل الإنتاج، مع سجل تغييرات ومراجعة قبل النشر.
