# تاجر — الزبون

هذه حزمة Expo مستقلة مخصصة لدور **الزبون** فقط. يبدأ التطبيق مباشرة من مسار الدور ولا يحتوي على شاشة اختيار دور أو هوية تجريبية.

## التشغيل

```bash
pnpm install
pnpm start
```

## البيانات

تمت إزالة السجلات الوهمية والأرقام الثابتة من واجهات المستخدم. البيانات تُقرأ من طبقة API/قاعدة البيانات بعد تسجيل الدخول، وعند عدم توفرها تظهر حالة فارغة بدلاً من بيانات تجريبية.

## المسارات الأساسية

- `/(tabs)`
- `/explore`
- `/shop/[id]`
- `/product/[id]`
- `/cart`
- `/orders`

> يلزم ضبط متغيرات البيئة الخاصة بالمصادقة وواجهة البيانات قبل التشغيل الإنتاجي.
